# 同步 MD 报告规范

每次同步（执行模式）必须产出一份 Markdown 报告，写入中央仓库 `reports/` 目录，文件名 `sync-YYYY-MM-DD-HHmmss.md`。报告内容可追溯、可粘贴到笔记或 Issue。

## 固定骨架

```markdown
# 同步报告 YYYY-MM-DD HH:mm

模式：执行 ｜ 中央仓库：`<hubDir>`

## 概要

新增 N · 合并重复 N · 挂载变更 N · 冲突 N · 跳过 N · 修复 N · 清理 N

## 新增收纳

| 技能 | 来源 | 动作 | 路径 |
|---|---|---|---|

## 重复合并

| 保留 | 合并掉 | 判定依据 |
|---|---|---|

## 冲突（待处理）

- **标题**：详情

同名异容冲突一律人工裁决（D4a），请在「去重与冲突」页处理。

## 挂载变更

| 技能 | 工具目录 | 动作 | 结果 |
|---|---|---|---|

## 变更明细（manifest diff）

```text
+ skills/<name> ← <tool>:<name> (sha256 前 12 位)
~ <name> @ <dir> 原目录备份 → .trash/<条目>
+ mount <name> @ <dir> → skills/<name>
```
```

## 规则

1. **每次执行同步必须产出报告**（干跑预览不产报告，只产动作清单）。
2. 空段落写「（无）」，不留空骨架。
3. 概要七项计数必须与明细一致。
4. 冲突条目与冲突队列（conflicts.json）内容一致。
5. 报告格式变更需同步更新本文档。
