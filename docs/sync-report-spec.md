# 同步 MD 报告规范

每次同步（执行模式）必须产出一份 Markdown 报告，写入中央仓库 `reports/` 目录。报告内容可追溯、可粘贴到笔记或 Issue。

- 本机同步（中央仓库 ↔ 各工具目录）：文件名 `sync-YYYY-MM-DD-HHmmss.md`
- 跨设备同步（中央仓库 ↔ WebDAV 远端）：文件名 `webdav-YYYY-MM-DD-HHmmss.md`

## 固定骨架

```markdown
# 同步报告 YYYY-MM-DD HH:mm

模式：执行 ｜ 中央仓库：`<hubDir>`

## 概要

新增 N · 合并重复 N · 挂载变更 N · 冲突 N · 跳过 N · 修复 N · 清理 N

## 新增收纳

| 技能 | 来源 | 动作 | 路径 |
|---|---|---|---|

## 重复合并

| 保留 | 合并掉 | 判定依据 |
|---|---|---|

## 冲突（待处理）

- **标题**：详情

同名异容冲突一律人工裁决（D4a），请在「去重与冲突」页处理。

## 挂载变更

| 技能 | 工具目录 | 动作 | 结果 |
|---|---|---|---|

## 变更明细（manifest diff）

```text
+ skills/<name> ← <tool>:<name> (sha256 前 12 位)
~ <name> @ <dir> 原目录备份 → .trash/<条目>
+ mount <name> @ <dir> → skills/<name>
```
```

## 规则

1. **每次执行同步必须产出报告**（干跑预览不产报告，只产动作清单）。
2. 空段落写「（无）」，不留空骨架。
3. 概要七项计数必须与明细一致。
4. 冲突条目与冲突队列（conflicts.json）内容一致。
5. 报告格式变更需同步更新本文档。

## WebDAV 跨设备同步报告骨架

```markdown
# WebDAV 同步报告 YYYY-MM-DD HH:mm

设备：<本机名> ｜ 服务器：`<endpoint><root>`

## 概要

下载 N · 上传 N · 冲突 N · 删除（远端 N / 本机 N）· 跳过 N

## 下载明细

| 技能 | 原因 | 内容哈希 |
|---|---|---|

## 上传明细

| 技能 | 原因 | 文件数 |
|---|---|---|

## 冲突（待处理）

- **技能名**：两台电脑都改了该技能（或本机新增与远端同名异容），远端版已暂存

跨设备冲突一律人工裁决，请在「去重与冲突」页处理。

## 删除记录

| 技能 | 位置 |
|---|---|

本机删除已进回收站，保留 7 天。
```

跨设备同步规则要点：三方合并以 `remote-state.json` 快照为 base；双边修改不自动选边（D4a），
远端版下载到 `.remote-staging/` 暂存并写入冲突队列；删除走 manifest 墓碑；远端孤儿目录自愈收录。
